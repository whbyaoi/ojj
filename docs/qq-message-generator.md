# QQ 消息事件发生器

## 范围与启动

接收单个 QQ 官方机器人账号的单分片 WebSocket 消息，写入现有事件存储；不发送消息、不实现 Webhook、不注册业务消费者，不改变事件模块契约。

启动前通过环境或秘密管理工具注入 QQ_APP_ID、QQ_CLIENT_SECRET。可选 OJJ_EVENT_DB 指定数据库路径，默认当前目录 events.db；父目录必须事先存在，同一数据库只允许一个进程持有。不要把凭证写入仓库或日志。

在项目根目录执行：

```sh
go run ./cmd/ojj
```

Go 版本要求见 [`go.mod`](../go.mod)。收到 SIGINT/SIGTERM 后取消接收，等待在途发布结束并关闭存储。配置或不可恢复错误导致非零退出。

平台侧需要启用对应权限并配置可接收消息的用户、群等范围。群全量消息还需启用“接收所有消息”，仅订阅 Intent 不代表平台已授权。

## 消息与事件映射

三种事件使用共同 Intent 位 25：

| QQ 事件 | 会话类型 | 会话标识 | 发送者标识 |
| --- | --- | --- | --- |
| C2C_MESSAGE_CREATE | private | author.user_openid | author.user_openid |
| GROUP_AT_MESSAGE_CREATE | group | group_openid | author.member_openid |
| GROUP_MESSAGE_CREATE | group | group_openid | author.member_openid |

统一生成 im.message，生产者身份为 qq.websocket。来源的平台为 qq，账号来自配置 AppID，消息标识为平台消息 id；OpenID 只在对应 AppID 范围内解释。发生时间取平台 timestamp 并转为 UTC。

正文是版本 1 的 JSON 文本，结构见 [`Content`](../internal/im/qq/message.go:81)：保留 QQ 事件类型、消息类型、原文、作者、消息/引用索引、场景、附件、mentions、ARK 卡片和递归消息元素。保留空白，不二次裁剪群 @ 前缀，不下载或执行附件。

输入限制为 1 MiB，生成正文最多 64 KiB；递归消息元素限制深度和总数。身份、时间、JSON 或正文尺寸无效时停止接收，不静默跳过。

## 去重与持久化

去重键是账号、QQ 事件类型、会话类型与标识、发送者、消息 id、附加区分值组成的 JSON 数组的 SHA-256，使用 qq:v1: 前缀。附加区分值优先采用 msg_idx，其次 msg_seq，两者均无则只依赖消息 id。索引只按首个等号拆分，保留尾部等号。

群 @ 和群全量事件不合并；WebSocket 外层序号不参与业务去重。同键且完整规范化事件一致时视为重复，同键内容变化由存储报告冲突。去重受事件存储保留期限约束，不是永久去重。

发布成功表示事件及当前匹配订阅投递已原子持久化，不代表业务处理完成。当前应用没有业务订阅；以后新增订阅不会回放此前事件。存储及投递契约见 [`event-module.md`](event-module.md)。

## 心跳、恢复与失败边界

读取、串行发布和心跳写入分开执行。心跳使用最新接收序号；Resume 使用已确认持久处理的序号。接收队列有界，满时断开并从保守游标请求重放，已提交但未推进游标的消息可能再次到达，由存储去重。

READY 后同步保存会话及初始游标。恢复收到首个有效派发后解除 15 秒握手期限，允许更长时间的补发；连接存活仍由心跳及 ACK 检查。未知事件按序处理并推进游标，不生成业务事件。

令牌提前刷新；连接达到刷新时间主动断开，再取新令牌并尝试 Resume。普通断线指数退避并加入抖动，默认从 1 秒增长至 1 分钟，连续不稳定连接失败默认最多 10 次。连接稳定至少 1 分钟后重置失败计数。Identify 至少间隔 5 秒；不支持多分片，Identify 配额耗尽时停止，Resume 不消耗该配额。

发布失败、非法消息、永久鉴权或协议错误停止接收，不越过失败消息。库调用方处理故障后，可对同一客户端再次调用 [`Run`](../internal/im/qq/session.go:37) 尝试恢复；禁止并发运行。同一客户端保留内存会话，但当前命令行应用遇到这些错误会退出。发布接口必须响应取消，退出时等待在途发布结束。

**恢复仅限内存会话和平台允许的短时窗口。** 进程重启、会话失效或重放窗口过期都可能产生消息缺口；重新 Identify 不等于补齐历史。本实现不承诺端到端恰好一次或断线绝不丢失。

## 安全与验证

API 只允许 HTTPS，网关只允许 WSS；API 禁止重定向。配置、原始响应、令牌和服务端关闭原因不写入日志。场景扩展只提取消息索引，丢弃 auth_token；ARK 自由字段递归过滤常见凭证键。用户正文和附件 URL 原样保存，不能保证识别其中用户自行携带的秘密，数据库仍应按敏感数据保护。

本地测试使用 HTTPS/WSS 模拟网关和真实 SQLite，覆盖映射、去重、发布失败恢复、READY 后立即断线、心跳 ACK、超过握手期限的补发及凭证刷新时的会话保留。短测试模式跳过约 16 秒的长补发回归。

```sh
go test ./...
go test -race ./...
go vet ./...
CGO_ENABLED=0 go test ./...
```

未使用真实 QQ 凭证连接官方平台。上线前仍须验证账号权限、网关获取、真实消息格式、断线恢复和令牌轮换。
